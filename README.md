# Sales Analytics Dashboard

An interactive sales analytics dashboard built with Python, Streamlit, Pandas, and Plotly.

## Features

* Key performance indicators for sales, profit, orders, and units sold
* Interactive region and category filters
* Monthly sales trend visualization
* Regional sales comparison
* Category-wise sales analysis
* Product profitability analysis
* Filtered sales data export to CSV
* Custom CSS styling

## Technologies Used

* Python
* Streamlit
* Pandas
* Plotly
* CSS

## Installation

Install the required packages:

```bash
py -m pip install streamlit pandas plotly
```

## Run the Application

```bash
py -m streamlit run app.py
```

## Dataset

Includes a small sample sales dataset for demonstration purposes. The figures do not represent real company sales.

## Project Purpose

Created as a portfolio project to practice Python data analysis, interactive visualization, and dashboard development.
